# 02. 신체기반 트라우마 치료 렌즈

> 말보다 몸이 먼저 반응합니다. 아동의 각성 상태와 신체 반응을 통해 안전감과 조절 능력을 봅니다.

## 핵심 개념
| 개념 | 핵심 내용 |
|---|---|
| 인내의 창 (Window of Tolerance; Siegel 1999, Ogden 등 2006 확장) | 각성이 견딜 만한 범위 안에 있을 때 경험을 처리·통합할 수 있음. 범위를 넘으면 **과각성**(불안, 공격, 과잉행동, 산만) 또는 **저각성**(멍함, 무표정, 해리, 무기력) |
| 상향식 처리 (bottom-up) | 이야기(인지)보다 신체 감각·움직임에서 출발해 조절과 처리를 돕는 접근. 하향식(top-down: 생각, 언어)과 대비 |
| 감각운동 심리치료 (Sensorimotor Psychotherapy; Ogden) | 신체 추적(tracking), 접촉 진술(contact statement), 몸에 대한 마음챙김 주의, 행동 경향성(action tendency), 중단된 방어반응(싸움·도피·얼어붙음·쓰러짐)의 완성, 신체 자원(somatic resource) 강화 |
| 신체경험 치료 (Somatic Experiencing; Levine) | 적정화(titration: 조금씩 다루기), 진자운동(pendulation: 불편감과 자원 사이 오가기), 자원화, 방출 |
| 신경순차적 모델 (Perry) | 조절(Regulate) → 관계(Relate) → 추론(Reason) 순서. 조절이 안 된 아동에게 말로 성찰을 요구하면 효과가 떨어짐 |
| 다미주신경 이론 (Porges) | 사회적 참여 / 투쟁·도피 / 얼어붙음 상태 모델. **현장에서 비유로 널리 쓰이지만 생리학적 전제는 학계에서 강하게 반박됨 (Grossman 2023)**. 사용 시 "임상적 비유"로만 표시할 것 |

## 확인 질문 (내담자 정보에 하나씩 대입)
1. 회기 중 각성 수준은 어떻게 변했는가? 과각성 신호(빨라진 말·움직임, 공격성, 산만)와 저각성 신호(멍함, 굳음, 목소리 작아짐, 하품, 해리)는 언제 나타났는가?
2. 각성 변화 직전의 촉발 장면(주제, 매체, 치료자 행동, 소리 등)은 무엇이었는가?
3. 신체 단서: 호흡(얕음/참음), 근긴장, 자세(웅크림/뻗음), 시선(회피/고정), 피부색, 목소리 톤, 움직임 속도의 변화는?
4. 아동이 스스로 진정하는 방법(자기조절 자원)이 관찰되었는가? (흔들기, 특정 물건 쥐기, 숨기, 반복 놀이 등)
5. 놀이나 작업에서 중단된 방어반응(밀어내기, 도망가기, 숨기 등)의 주제가 보이는가?
6. 현재 아동에게 더 필요한 것은 안정화·자원 강화인가, 기억 처리인가?

## 개입 시 고려할 근거
- 트라우마 치료는 일반적으로 **안정화 → 처리 → 통합** 단계를 따릅니다(Herman 1992 단계모델). 인내의 창이 좁은 아동은 안정화와 자원 강화가 먼저입니다. [이론]
- 조절이 무너진 상태에서는 리듬, 반복, 감각 입력(무게감, 누르기, 밀기) 같은 상향식 개입이 먼저입니다. [이론·임상관례]
- 적정화: 힘든 주제는 아주 작은 단위로 다루고 곧바로 자원으로 돌아옵니다. [이론]

## 근거 수준
- Somatic Experiencing: 성인 PTSD 대상 무작위 대조 연구가 있으나(Brom 등 2017) 수가 적고, 아동 대상 근거는 제한적입니다.
- Sensorimotor Psychotherapy: 임상 보고와 소규모 연구 위주이며 대규모 무작위 대조 연구는 부족합니다.
- 다미주신경 이론: 임상적 유용성을 주장하는 쪽과 생리학적 전제가 반박되었다는 쪽이 대립합니다. 기제 설명으로 단정해 쓰지 마십시오.
- 아동 트라우마 치료에서 가장 근거가 탄탄한 것은 TF-CBT(외상중심 인지행동치료)입니다. 필요 시 함께 언급하십시오.
