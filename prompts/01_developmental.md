# 01. 발달심리학 렌즈

> 모든 분석의 바탕입니다. 아동의 행동을 "이 연령에서 기대되는 수준"과 비교해 이해합니다.

## 핵심 개념
| 이론 | 핵심 내용 |
|---|---|
| 피아제 인지발달 | 감각운동기(0~2세) → 전조작기(2~7세: 상징놀이, 자기중심성) → 구체적 조작기(7~11세: 보존, 논리적 분류) → 형식적 조작기(11세~: 추상적·가설적 사고) |
| 에릭슨 심리사회 발달 | 신뢰 대 불신(영아) → 자율성 대 수치심(1~3세) → 주도성 대 죄책감(3~6세) → 근면성 대 열등감(6~12세) → 정체감 대 혼미(청소년) |
| 애착이론 (Bowlby, Ainsworth, Main & Solomon) | 양육자를 안전기지로 삼아 탐색. 애착 유형: 안정 / 불안정-회피 / 불안정-저항(양가) / 혼란. 내적작동모델이 이후 관계 기대를 형성 |
| 위니컷 | 충분히 좋은 엄마(good-enough mother), 안아주는 환경(holding environment), 중간대상, 놀이할 수 있는 능력 자체가 건강의 지표 |
| 정신화 (Fonagy) | 자신과 타인의 행동을 마음 상태(감정, 의도)로 이해하는 능력. 안정 애착 속에서 발달 |
| 그림 발달 단계 (Lowenfeld & Brittain) | 난화기(2~4세) → 전도식기(4~7세) → 도식기(7~9세: 기저선, 반복 도식) → 또래집단기(9~12세) → 의사실기(12~14세) |
| 발달정신병리 (Cicchetti) | 동일결과성(다른 경로가 같은 결과로) / 다중결과성(같은 위험요인이 다른 결과로). 위험요인과 보호요인을 함께 봄 |
| 공동조절 → 자기조절 | 영유아는 양육자와의 공동조절(co-regulation)을 통해 점차 스스로 정서를 조절하게 됨 |

## 확인 질문 (내담자 정보에 하나씩 대입)
1. 아동의 생활연령에서 기대되는 인지·언어·정서·사회성 수준은 무엇이며, 실제 관찰과 차이가 있는가?
2. 현재 에릭슨 발달과업은 무엇이며, 이전 과업에서 미해결된 흔적이 보이는가?
3. 애착 패턴을 추정할 단서가 있는가? (분리·재회 장면, 치료자에게 접근하는 방식, 도움 요청 방식)
4. 그림이나 조형물이 그림 발달 단계상 연령에 맞는가? 퇴행 또는 조숙한 표현이 있는가?
5. 놀이 능력(상징놀이, 규칙놀이, 놀이의 지속과 확장)은 어떠한가?
6. 위험요인과 보호요인은 각각 무엇인가?
7. 아동의 정서조절은 공동조절이 더 필요한 단계인가, 자기조절을 키울 단계인가?

## 개입 시 고려할 근거
- 발달 수준에 맞지 않는 개입(예: 전조작기 아동에게 추상적 언어 성찰 요구)은 효과가 떨어집니다. 발달 수준에 맞는 놀이·매체·언어를 고르십시오. [이론]
- 애착 손상이 의심되면 기법보다 관계의 일관성과 예측 가능성이 우선입니다. [이론]

## 한계와 주의
- 단계별 연령은 평균이며 개인차와 문화차가 큽니다. 단계 이론으로 아동을 단정하지 마십시오.
- 상담실 안 짧은 관찰만으로 애착 유형을 단정할 수 없습니다. 애착 평가는 표준화된 절차가 따로 있습니다.
