# 04. 게슈탈트 렌즈

> '왜'보다 '지금 무엇을, 어떻게' 하고 있는지에 주목합니다. 아동이 세상과 어떻게 접촉하고, 어디서 접촉을 끊는지 봅니다.

## 핵심 개념
| 개념 | 핵심 내용 |
|---|---|
| 지금-여기, 알아차림 | 과거 해석보다 현재 경험(감각, 감정, 행동)의 알아차림이 변화의 출발점 |
| 접촉과 접촉경계 | 자신과 환경이 만나는 지점. 건강한 접촉은 감각을 통해 이뤄짐 |
| 접촉경계 혼란 | **내사**(남의 기준을 그대로 삼킴), **투사**(자기 감정을 남의 것으로 봄), **반전**(남에게 할 것을 자신에게 함: 자해, 자기비난, 몸 긴장), **융합**(경계 없음), **편향**(직면 회피, 화제 돌리기), **자의식** |
| 전경과 배경 | 지금 가장 중요한 욕구가 전경으로 떠오르고 해소되면 배경으로 물러남 |
| 미해결 과제 | 완결되지 못한 감정·욕구가 반복적으로 떠오름 |
| 변화의 역설 (Beisser 1970) | 사람은 자기 아닌 것이 되려 할 때가 아니라, 있는 그대로의 자신이 될 때 변화함 |
| 경험의 주기 (Zinker) | 감각 → 알아차림 → 에너지 동원 → 행동 → 접촉 → 해소·철수 |
| 오클랜더 아동 게슈탈트 모델 | 치료적 관계 → 접촉 → **자기감 강화**(감각, 몸, 선택, 숙달, 공격적 에너지의 건강한 표현) → 정서 표현 → 자기 돌봄 → 지속되는 행동 다루기. 그림·점토·모래 등으로 투사를 활용 |

## 확인 질문 (내담자 정보에 하나씩 대입)
1. 아동은 치료자, 매체, 공간과 어떻게 접촉하는가? 접촉이 끊기는 순간은 언제인가?
2. 어떤 접촉경계 혼란이 두드러지는가? (예: "나는 원래 나쁜 애야" → 내사, 화날 때 자기 몸 때리기 → 반전, 화제 전환 → 편향)
3. 회기에서 반복적으로 떠오르는 전경(주제, 욕구)은 무엇인가? 미해결 과제의 흔적이 있는가?
4. 자기감의 상태: 아동은 선택할 수 있는가? 싫다고 말할 수 있는가? 자신의 감각을 알아차리는가?
5. 공격적 에너지(밀기, 부수기, 소리 지르기)는 억눌려 있는가, 통제되지 않는가, 건강하게 표현되는가?
6. 경험의 주기 중 어디에서 막히는가? (감각 둔화, 알아차림 부족, 행동으로 옮기지 못함, 마무리 못함)

## 개입 시 고려할 근거
- 그림이나 점토 형상이 "되어서" 말해보기(나는 이 화산이야…)는 투사된 부분을 자기 것으로 되찾는 게슈탈트 기법입니다. [이론]
- 자기감이 약한 아동에게는 정서 표현 전에 감각 활동과 선택 경험(재료 고르기, 거절해보기)으로 자기감을 먼저 세웁니다(Oaklander). [이론]
- 실험(experiment)은 강요가 아니라 초대이며, 아동이 거절할 수 있어야 합니다. [이론]

## 근거 수준
- 게슈탈트 치료 전반에 대한 실증 연구는 증가하고 있으나, 아동 게슈탈트 놀이치료를 검증한 대조 연구는 제한적입니다. 주로 임상 사례와 질적 연구에 근거합니다.
