# [출력 양식] 상담일지

입력된 키워드와 문장을 바탕으로 아래 양식의 상담일지를 작성하십시오.

## 작성 원칙
1. **관찰과 해석을 분리**하십시오. 관찰은 객관적 사실로, 해석은 "~로 보임", "~의 가능성" 같은 가설로 씁니다.
2. 판단이 담긴 단어 대신 **구체적 행동**으로 쓰십시오.
   - ✕ "산만했다" → ○ "회기 중 자리에서 6회 일어나 교구장으로 이동함"
   - ✕ "기분이 좋아 보였다" → ○ "미소 지으며 '또 하고 싶어요'라고 말함"
3. 아동의 말은 **큰따옴표로 직접 인용**합니다.
4. 신체 반응(호흡, 자세, 표정, 움직임 속도)과 매체 경험(촉감, 저항, 반응)을 빠뜨리지 마십시오.
5. 문장은 "~함", "~보임" 형태의 간결한 개조식으로 씁니다.
6. 실명, 학교명, 지역은 익명 처리합니다.
7. 입력되지 않은 내용은 지어내지 말고 "(기록 없음)" 또는 "[보완 필요: ○○]"로 표시합니다.
8. **"회기 메모"에 문장으로 서술된 내용**(예: "오늘 아동과 클레이를 했고 처음엔 손끝만 대다가 점점 손바닥 전체로 만졌다")은 문장을 쪼개 활동·매체, 관찰(행동·정서·신체·언어), 치료자 개입, 아동 반응으로 **구분해서 양식의 해당 칸에 배치**하십시오. 다른 칸에도 같은 내용이 있으면 합쳐서 한 번만 씁니다. 메모에 없는 내용은 덧붙이지 마십시오.

## 일지 뒤에 덧붙일 것
1. **기술 팁**: 이번 일지에서 표현을 다듬은 이유 2~3개 (예: 어떤 판단어를 행동 기술로 바꿨는지)
2. **보완하면 좋을 관찰**: 다음 회기에 더 기록하면 좋은 항목
