# 농지니

키워드만 넣으면 **사례 분석 / 상담일지**를 바로 만들어주는 웹페이지입니다.
사용자가 등록한 구글 무료 이용 키(Gemini API)로 브라우저에서 직접 생성합니다. 입력 내용은 저장하지 않습니다.

> 무료 이용 시 입력 내용을 구글이 품질 개선에 활용할 수 있으므로, 아이를 알아볼 수 있는 정보는 넣지 않습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 |
| `prompts/manifest.json` | 이론 순서, 기본 체크, 입력 칸 목록 |
| `prompts/00_role.md` | 역할과 기본 원칙 |
| `prompts/01~08_*.md` | 이론별 참고자료 (핵심 개념, 확인 질문, 개입 근거, 근거 수준, 참고문헌) |
| `prompts/90_analysis_format.md` | 사례 분석 출력 양식 |
| `prompts/91_journal_format.md` | 상담일지 출력 양식 |

## 질문문 조립 순서

역할과 원칙 → 선택한 이론(번호 순) → 출력 양식 → 입력 정보 → 마무리 지시

## 수정 방법

- 문구, 양식, 입력 칸은 `prompts/` 폴더의 파일을 수정해 올리면 모든 기기에 영구 반영됩니다.
